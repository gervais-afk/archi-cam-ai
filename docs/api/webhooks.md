# Webhooks Reference

Configurez des Webhooks pour recevoir des notifications en temps réel lors du traitement asynchrone des maquettes lourdes.

## Événements Supportés

*   `conversion.completed` : Déclenché lorsque la conversion CAO vers IFC d'Antygravity Cloud est terminée.
*   `conversion.failed` : Déclenché en cas d'erreur de conversion.
*   `audit.completed` : Déclenché lorsque l'audit des règles BAEL 91 et POS de Yaoundé/Douala est finalisé.
