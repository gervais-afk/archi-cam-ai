# Archi Cam AI 🏛️🚀

**Archi Cam AI** is a premium, B2B-ready ConTech (Construction Technology) SaaS platform designed to revolutionize the architectural and construction landscape in Cameroon. Leveraging state-of-the-art AI and BIM (Building Information Modeling) capabilities, it streamlines complex workflows from IFC parsing to automated regulatory documentation.

![Project Banner](https://images.unsplash.com/photo-1486406146926-c627a92ad1ab?auto=format&fit=crop&q=80&w=2070)

## 🌟 Key Features

- **High-Precision BIM Parsing**: Seamless integration with IFC (Industry Foundation Classes) files for detailed structural analysis.
- **Automated CCTP & DQE Generation**: Generate professional Technical Specifications (CCTP) and Estimated Cost Statements (DQE) in minutes.
- **Intelligent Architectural Analysis**: AI-driven insights for project optimization and regulatory compliance.
- **Premium UI/UX**: A sophisticated dark-mode design system built with Framer Motion for smooth, professional interactions.
- **Localized for Cameroon**: Tailored to local architectural standards and construction practices.

## 🛠️ Technology Stack

- **Frontend**: [Next.js 14](https://nextjs.org/) (App Router), [React 18](https://react.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/), [Framer Motion](https://www.framer.com/motion/)
- **Backend/Database**: [Supabase](https://supabase.com/), [Firebase](https://firebase.google.com/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Design System**: Radix UI & Lucide Icons

## 🚀 Getting Started

### Prerequisites

- Node.js 18.x or higher
- npm / yarn / pnpm

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/gervais-afk/archi-cam-ai.git
   cd archi-cam-ai
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Environment Variables**:
   Create a `.env.local` file in the root directory and add your credentials (refer to `.env.example` if available).

4. **Run the development server**:
   ```bash
   npm run dev
   ```

## 🔐 Security & Privacy

This project is maintained in a private repository to protect proprietary algorithms and sensitive architectural data. 

- **No Secrets Policy**: API keys and sensitive credentials are never committed to the repository. They are managed via environment variables and secure secrets management.
- **BIM Data Privacy**: All IFC and project data are processed with strict confidentiality.
