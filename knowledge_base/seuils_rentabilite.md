# GRILLES SALARIALES ET RENTABILITÉ (MARCHÉ CAMEROUNAIS)

[Salaires Mensuels] -> [Ouvrier BTP / Gros Œuvre] -> La fourchette salariale de base est comprise entre 95 435 FCFA (salaire minimum) et 294 043 FCFA.
[Salaires Mensuels] -> [Technicien Spécialisé] -> Un technicien (ex: plomberie, installation sanitaire, électricité) perçoit entre 100 000 FCFA et 300 000 FCFA selon la complexité du marché.
[Taux Horaire Moyen] -> [Base de calcul] -> Le taux horaire moyen de la main d'œuvre non qualifiée à utiliser pour le Déboursé Sec est estimé à 870 FCFA / heure (avant application des charges CNPS).
[Alertes Financières] -> [Sanity Check] -> Tout budget prévisionnel dont la main-d'œuvre est inférieure au salaire minimum sectoriel ou omettant les cotisations CNPS doit être signalé comme "Anormalement bas".
